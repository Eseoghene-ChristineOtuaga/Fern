# Fern — Understand to play better Chess

Fern is a calm, responsive chess study app. Import a PGN, replay a game, analyse it with **Stockfish 19 Lite running locally in your browser**, and revisit the moves that changed the evaluation.

## MVP Features

- Paste a PGN, upload a `.pgn` file, or try the sample game
- Replay moves on an interactive chessboard; flip the board and control playback
- Run local Stockfish analysis at **Quick (depth 10)**, **Standard (depth 12)**, or **Deep (depth 16)**
- See engine evaluation, suggested best moves, and provisional move labels
- Read short rule-based explanations and step through important moments
- Save up to 25 games in your browser's local library

**Important:** Move labels are approximate classifications derived from engine evaluations; they are not definitive chess judgments. The app's explanations are rule-based, not generated by an AI model.

## Run it locally

Requires Node.js 22 or a compatible recent version.

```bash
npm install
npm run dev
```

Open the address printed by Vite. To test and build:

```bash
npm test
npm run build
```

For the browser Stockfish benchmark:

```bash
npx playwright install chromium
npm run bench:browser
```

The Vite plugin copies Stockfish's matching JavaScript and WebAssembly files from the installed npm package into `public/engine/`, which are served from the same origin. No backend API key or paid service is necessary.

## How Fern works

1. `chess.js` validates the PGN and produces legal moves and board positions.
2. A Stockfish Web Worker analyses each position at the selected depth, without blocking the UI.
3. Fern compares evaluations before and after each played move from the mover's perspective.
4. It assigns **provisional** labels using changes in estimated expected score, prioritizes larger mistakes, and displays engine suggestions.
5. Saved PGNs live in browser `localStorage`. Clearing browser storage or using another device does not preserve them.

## Repository layout

| File | Responsibility |
| --- | --- |
| `src/App.jsx` | Study, Review and Library screens; import, replay, analysis state |
| `src/engine.js` | Stockfish Web Worker and UCI messaging |
| `src/review.js` | Expected-score calculations, provisional grades, explanations |
| `src/styles.css` | Responsive visual design |
| `vite.config.js` | Copy/serve Stockfish JS and WASM assets |
| `tests/` | Logic tests, validation fixtures, browser and native engine benchmarks |
